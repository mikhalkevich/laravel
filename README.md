 
## Интернет магазин и API запросов

Laravel project

## Информация по установке
- Установка проекта

```bash
git clone ...
```
- cd laravel
- composer install
- npm i
- создать базу и подключиься к ней в файле .env
- php artisan optimize:clear
- php artisan migrate

Запуск проекта:
- cd laravel
- php artisan serve
- npm run dev
